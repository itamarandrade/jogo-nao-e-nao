NÃO PRECISA INSTALAR NADA.
Só é preciso ter o Google Chrome (ou o Microsoft Edge).


COMO ABRIR
----------

  Windows ....... dê dois cliques em  abrir-jogo.bat
  Linux / Mac ... execute            ./abrir-jogo.sh

O jogo abre em tela cheia. Para sair da tela cheia: Alt + F4.


ANTES DO EVENTO — FAÇA ISTO UMA VEZ
-----------------------------------
É o passo que garante que os cadastros fiquem salvos.

  1. Abra o painel:
       Windows ....... abrir-jogo.bat painel
       Linux / Mac ... ./abrir-jogo.sh painel

  2. Vá na aba "Cadastros".

  3. Clique em "Conectar arquivo CSV".

  4. Escolha onde salvar o arquivo.
     Sugestão: um pen drive, ou uma pasta fácil de achar.

  5. Confirme que a faixa no topo ficou VERDE.

Pronto. A partir daí, cada pessoa que se cadastrar é gravada
NA HORA nesse arquivo. Não precisa exportar nada no fim do dia.


PARA QUE SERVE ESSE PASSO
-------------------------
Sem ele, os cadastros ficam guardados apenas dentro do
navegador — e somem se alguém limpar os dados de navegação ou
se o computador for formatado.

Com o arquivo conectado, existe uma cópia de verdade no disco,
que sobrevive a tudo isso.


SE A FAIXA DO PAINEL MUDAR DE COR
---------------------------------
  VERDE ....... tudo certo, gravando no arquivo.

  AMARELA ..... os cadastros estão só no navegador.
                Clique em "Conectar arquivo CSV".

  VERMELHA .... o navegador não grava direto no arquivo
                (provavelmente Firefox). Use Chrome ou Edge.
                Enquanto isso, o jogo baixa um arquivo CSV
                completo a cada 5 cadastros — guarde o mais
                recente da pasta de Downloads.

Se o Chrome for fechado e aberto de novo durante o evento, o
navegador pode perguntar de novo se pode gravar no arquivo.
Basta tocar na tela inicial do jogo e responder "Sim" — a
gravação volta sozinha.


PAINEL DE CONTROLE
------------------
  Windows ....... abrir-jogo.bat painel
  Linux / Mac ... ./abrir-jogo.sh painel


  >>> DURANTE O EVENTO, com o jogo em tela cheia:
  >>>
  >>>   TOQUE 5 VEZES SEGUIDAS NO CANTO SUPERIOR ESQUERDO
  >>>
  >>> Funciona em qualquer tela do jogo. Os toques precisam ser
  >>> seguidos (sem parar mais de 2 segundos entre um e outro);
  >>> se parar, a contagem recomeça.

  A área é invisível e não é anunciada na tela — é só para quem
  está operando. ATENÇÃO: quem chegar ao painel pode apagar os
  cadastros ("Limpar Dados"), então não mostre o atalho ao
  público.

  Há também uma engrenagem na tela de escolha do jogo, mas ela
  só aparece depois de se cadastrar — por isso o atalho do canto.

No painel dá para:
  - ligar/desligar o formulário de cadastro (nome, CPF e
    consentimento) ou usar o modo simples, que pede só o nome;
  - impedir que o mesmo CPF jogue duas vezes;
  - ver quantas pessoas jogaram;
  - trocar cores, logo e o conteúdo dos três jogos.

  ATENÇÃO: depois de mexer em qualquer configuração, clique em
  SALVAR, no rodapé da tela.

  As configurações ficam guardadas NAQUELE computador. Se o
  evento usar mais de um totem, configure cada um.


O ARQUIVO DOS CADASTROS
-----------------------
É uma planilha que abre no Excel, no LibreOffice e no Google
Planilhas.

  * Se abrir tudo numa coluna só, escolha ponto e vírgula ( ; )
    como separador na hora de importar.

Colunas: ID, Nome, CPF, Consentimento, Cadastro completo,
Data, Hora, Timestamp.


SE O EVENTO TIVER MAIS DE UM TOTEM
----------------------------------
Cada totem grava o seu próprio arquivo. Para juntar tudo:

  1. copie o arquivo CSV de cada totem;
  2. no painel de um deles, clique em "Restaurar de um CSV" e
     escolha o arquivo do outro.

Os cadastros são unidos sem duplicar.

Obs.: a verificação de CPF repetido funciona dentro de cada
totem. Entre totens diferentes, só depois de juntar os arquivos.


MODO AUTOMÁTICO (OPCIONAL, PARA QUEM TEM PYTHON)
------------------------------------------------
Existe um modo em que o arquivo é criado sozinho, sem o passo
de escolher onde salvar. Ele exige o Python instalado.

  python3 servidor.py 8123

Depois abra  http://localhost:8123/index.html

Nesse modo o arquivo fica em  dados/jogadores.csv  e o painel
ganha um botão "Ver o arquivo", que abre a pasta.

Isto é uma comodidade, não uma necessidade: o modo normal
(dois cliques no atalho) grava igualmente bem.


PROTEÇÃO DOS DADOS (LGPD)
-------------------------
Quando o formulário completo está ligado, o jogo coleta NOME e
CPF, com autorização da pessoa marcada na tela.

O arquivo CSV contém esses dados em texto comum. Ele fica
apenas no computador do totem (ou no pen drive escolhido) — não
é enviado para nenhum servidor ou serviço na internet.

Recomendações:
  - copie o arquivo para um local seguro ao fim do evento;
  - apague os dados do totem depois de copiar (painel > aba
    Cadastros > "Limpar Dados", e apague o arquivo CSV);
  - defina quem terá acesso ao arquivo e por quanto tempo ele
    será guardado.

Se o objetivo for apenas contar quantas pessoas participaram,
considere usar o MODO SIMPLES (só o nome, sem CPF): coleta-se
menos dado pessoal e a finalidade continua atendida.
